# For developers
We welcome contributions! You can add new features or report/fix bugs in MatrixShuffle. But follow these simple rules:
* Use **PascalCase** for methods, object names, file names, etc.
* Test your code
* Make your code **clear**.
* If you make changes, create a **pull request** and describe your changes.

# For users
If you find a bug in MatrixShuffle, or you want add new things write about it in **issue tracker**.
